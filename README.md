A chess engine in under 4 KB of Python, built for the make.fun tiny-chess-01 bounty. The engine is main.py (a self-extracting compressed payload; the readable source was developed and tested locally). It plays through the competition env at MAKEFUN_ENV_URL with a fixed node budget, fully deterministic.

## Run it

```sh
MAKEFUN_ENV_URL=<competition-env-url> python3 main.py
```
